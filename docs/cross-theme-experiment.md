# 跨主题泛化实验：视觉隐喻驱动设计（提交见文末）

- 基线：`9ecedd9`；实验目录：`experiments/metaphor/`（全部增量）
- 研究问题：视觉隐喻能否跨主题推导出更有辨识度的构图/信息组织/交互叙事，而非新风格标签？

## 一、协议

三主题 × 两流程。基线=现有正式管线真实生成（`POST /api/generate`）；隐喻版=LLM 推导 8 项中间产物（`brief-metaphor.mjs` 真实调用）+ 按产物实现首屏（零外部素材）。变量控制：需求文本一致、同视口 1440×900、同机同浏览器；**不可控变量如实记录**——基线火山走采集管线（真实照片），隐喻版全部程序化视觉；隐喻版由人工按产物实现（代表"理想执行上界"，非管线自动产出）。

生成记录：基线 火山 PMVD750X2（176s）/点茶 PMVD78T98（44s）/咖啡 PMVD79RA4（44s）；隐喻推导 3 次调用全一次通过（17.9s / 25.2s / 18.9s，0 重试）。

## 五、分析（逐主题）

1. **隐喻改善来源**：概念辨识度/交互叙事/信息组织三项 6:0 全胜且差距大（2→5）；这些改善**来自隐喻本身**——基线与隐喻版的关键差异不是提示词长度（基线也有 Design Brief），而是隐喻把内容结构钉在了视觉结构上。
2. **基线仍占优处**：主视觉表现力（火山 5:3、咖啡 4:3）——**因为基线有真实照片而隐喻版零素材**。这是实验约束（程序化）造成的混杂变量，非隐喻缺陷；正式系统隐喻版可叠加采集图。
3. **新问题（如实）**：隐喻火山首屏视觉重量不足（概念正确但张力弱）；点茶隐喻首屏信息密度偏低（雅致vs空洞一线之隔）；两者提示"隐喻≠自动好构图"，仍需 focalObject 体量校准。
4. **反例主题**：无完全反例，但火山主题最接近平局——当需求以"看真实东西"为主时，照片冲击仍是硬需求。
5. **证据充分性**：3 主题×1 评审者×模型判断——支持"方向有效"，不足以支持"普遍有效"。

## 六、决策：**调整后再测**（三个选项中）

依据：概念维度收益显著且可解释，但 (a) 混杂变量（素材差异）未剥离，(b) 单评审者模型判断，(c) 隐喻版为人工理想执行而非管线自动产出。**下一步实验**（未执行）：①隐喻版叠加真实采集图重测火山主题剥离素材变量；②隐喻产物→自动渲染（而非人工实现）打通后才具备推广前提；③第二评审者（用户）抽评两对版本。
