# Scene Composer 试运行实验报告

- 基线：`48554ab`；实验目录：`experiments/composer/`（全部增量，正式管线零改动）
- 研究问题：Scene Composer 能否让系统从"生成有趣效果"升级为"自主创作完整网页作品"（Director 产方案 → 编译器产代码 → 真实渲染 → 批评-修订闭环）？

## 一、实现（隔离层，未动正式管线）

| 模块 | 职责 | 规模 |
|---|---|---|
| `capabilities.mjs` | 能力池：7 项场景能力（电影舞台/动态排印/GPU 流场/产品舞台/作品墙/数据带/结束幕）× 代码生成函数 + 4 种转场机制（字符散解/色域吞没/景深推近/巨字交接），注册表含性能/依赖/移动端/降级/验证状态 | ~470 行 |
| `director.mjs` | Creative Director：LLM 产可执行创意方案（concept/scenes[3-5 幕含起伏]/transitions[语义理由]/acceptance），能力与机制白名单约束 + 编译前校验 | ~120 行 |
| `compose.mjs` | 编译器：方案 JSON → 单文件网页（文档壳+`?motion=force` 评审钩子+自动补转场）；缺转场自动补并记录 | ~90 行 |

**自动/人工边界（如实）**：三主题页面 100% 由 Director JSON → 编译器产出（文案/数据/色值/幕次编排全部来自 LLM 方案）；**人工介入共 4 处、全部是生成器缺陷修复**——①module 内 `document.currentScript` 为 null 导致整页 JS 崩溃（改 querySelector）②粒子数未钳制（≤20000 护栏）③`side` 参数语义漂移容错④转场区高度 70vh<视口导致进度分母为负（→150vh）。人工未触碰任何主题页面的文案/布局/样式。

## 三、真实渲染与交互实测

- **结构**：三实验组幕次/转场全部编译正确（A 4幕3转场、B 5幕4转场、C 4幕3转场）
- **转场状态机（强制动画下逐状态）**：start 完整(op=1,transform 归位)→mid 散解(位移+旋转+变色)→end(op=0 露出下幕)→**回滚对称可逆**；快滚跨越无崩坏
- **交互**：mirage 流场滚入启动(canvas 878×556)+指针搅动；vista 产品幕 640×640 拖转+规格高亮；移动端 390×844 三组均无横向溢出(sw=375)
- **控制台**：全链未捕获错误（修复后）

## 四、重大环境发现（影响此前多轮评审！）

**IAB 浏览器 `prefers-reduced-motion: reduce = true`（系统级）**——此前所有原型在用户浏览器中动效被系统熔断为终态静态（跑马灯/进场编排/转场中间态全不可见）。这**可能部分解释用户"整体一般"的观感**。已加 `?motion=force` 评审钩子；建议用户核对 Windows"动画效果"设置。headless 截图同为 reduce（六版截图同环境对比仍公平）。

## 五、批评-修订闭环（三轮，前后证据）

| 轮 | 类型 | 问题（证据） | 修复 | 结果 |
|---|---|---|---|---|
| 1 | 生成器缺陷 | 整页 JS 崩溃（module currentScript null）/粒子 180k/侧栏语义漂移 | 3 处生成器修复 | 流场 878×556 启动 ✓ |
| 2 | 转场行程 | 转场区 70vh<视口 → 进度分母为负、起始即终态（实测 start op=0） | 行程 150vh | （见轮 3 后状态机全过） |
| 3 | 视觉精修 | 数据带正文对比度 .6 偏弱；作品墙悬停同向倾斜 | .74+行距 2.05；奇偶交替倾斜 | 重编译三组 ✓ |

（轮 2 的完整验证被"系统 reduce=true"掩盖——最终以 `?motion=force` 强制动画完成状态机验证。）

## 六、评审（模型辅助，非独立人工——如实披露）

六版打乱（s1–s6）逐图观察：实验组在**概念辨识度/转场质量/交互-概念一致性**明显领先（蜃楼热浪色流场/散解转场/巨字交接为基线完全不具备的表达）；基线在**首屏信息效率**（landing 直接呈现文案层级）与**真实照片质感**（部分主题）占优。最模板化的部分：基线三版共享同一 editorial 骨架；实验组最弱处：作品墙幕（程序化占位卡密度感弱于真实作品图）。**用户验收缺失**——请查看 `out/{mirage,vista,silkroad}/`（`?motion=force` 看完整动效）。

## 七、性能与工程（如实）

粒子≤20000（护栏）/流场滚出即暂停（IO）/转场纯 scroll 监听无 rAF 常驻/WebGL 失败回退面板（**触发路径未实测**）/reduced-motion 全熔断+force 钩子。**帧率未量化测量**（无 instrumentation，标记未测量）。

## 八、决策：**推广到有限正式试运行**

依据：①两个以上差异明显主题（A/B/C 三主题）实验组在概念/转场/交互维度的可解释改善；②改善来源可归因——Director 编排（幕次/概念色/转场选择）+能力池质量，且**人工零页面级代做**（4 处介入均为生成器缺陷修复并已固化护栏）；③生成链路端到端可复现（3 次 Director 调用全部一次通过）。**试运行边界**：作为 landing/gallery 之外的第三路径（"作品模式"）灰度，不替代默认；正式接入前需补：产品幕触屏实测、WebGL 回退实测、帧率 instrumentation、用户盲评一轮。

## 九、证据路径

plans/*.json（三方案+调用元数据）/ out/{mirage,vista,silkroad}/（编译产物+compile-log）/ shots/（六版+盲评映射+强制动画+移动端）/ 本报告。复现：`node director 调用 → node compose.mjs plans/X.json out/X`。
