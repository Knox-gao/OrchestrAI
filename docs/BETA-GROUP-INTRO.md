## 群公告版（推荐置顶）

### OrchestrAI 内测 · 一句话，做成能用的网站

你描述想要什么，它组织一组 AI Agent 自己干完：**理解需求 → 规划页面结构 → 找配图 → 写页面 → 跑真实测试 → 在浏览器里验收 → 打包交付**。

最后给你一个能直接打开的网页，下载 ZIP 解压就能独立运行，不需要装任何运行时。

---

**它和别的 AI 建站工具有三点不一样：**

**① 不是填模板，是真的在规划页面**
模型先产出一份结构化的页面计划（章节、层级、配色、字体气质、交互），再由渲染器把它变成页面。所以换个主题，页面结构本身也会跟着变，而不是套同一个壳换张图。

**② 有质量门禁，不合格就不交付**
交付前要过一整套检查：静态结构、真实单测（`node --test` 真的跑）、交互绑定与素材完整性、浏览器实渲染、离线素材打包、必需需求覆盖、最终验收。

其中**静态结构不过、单测不过、必需素材缺失、渲染失败、必需需求没满足**，都会直接阻断交付并告诉你卡在哪 —— 不会给你一个勉强能看的壳子假装成功。另外还有一道基于关键词的需求覆盖提示，它只作为告警列在事件日志里，不阻断交付（这点我在界面上标注了）。

**③ 审美的事它问你，不替你做主**
开工前 AI 会先判断：有没有需要你拍板的主观选择（字体气质、视觉风格、页面方向、文案调性）。有的话弹选择卡让你选，每个问题都可以选「让你决定」交回给 AI。

---

**内测版能做的**

- 一句话或一份 Word / TXT / Markdown 需求文档，生成桌面版网页
- 148 种视觉风格（16 种精工基底 × 9 种色彩气质 + 4 个工作室联名），也可以自己写描述
- 自动配图：优先搜真实图片并保留作者/许可/来源，搜不到就按主题画矢量插画补位
- 四种页面动效档位
- 生成过程全程可见：像素办公室里能看到每个 Agent 在干什么，事件日志里能看到每道门禁的结果
- 项目库：历史项目、交付状态、素材、ZIP 下载都在

**内测版暂时不做的**（先说清楚，省得你试了失望）

- 只出桌面版网页，不做移动端适配，不打包 .exe / .apk
- 只做单页，还没有多页路由
- 3D 场景能力在引擎里已经通了，但真实模型还没有稳定用上，可能一次都触发不到
- 质量还不稳定：简单主题（介绍页、展馆、倒计时、打卡）明显更好，复杂信息架构容易变平庸

**怎么开始（目前是本地运行）**

需要 Node 20+，然后是三步：

```bash
# 1. 装依赖
npm install

# 2. 起后端（http://127.0.0.1:8787）
node apps/server/index.mjs

# 3. 起前端（http://localhost:5175）
npm run dev
```

打开 `http://localhost:5175`，点右上角 **🔑 模型与图源** → **自定义服务**，填你的模型：

| 字段 | 填什么 |
|---|---|
| 服务名称 | 随便，比如 `my-deepseek` |
| 接口地址 | OpenAI 兼容地址，比如 `https://api.deepseek.com/v1` |
| API Key | 你的密钥 |
| 模型名 | 比如 `deepseek-chat` |

> **必须自带模型。** 没配模型时生成会直接阻断并提示你去配 —— 这是故意的，只产出模板页没有意义。
> 密钥只存在你本机的 `apps/server/keys.json`，接口只返回掩码，不写日志、不进入交付包。

配好之后：首页给项目起个名字 → 左下角对话框输入需求 → 如果弹选择卡就选一下 → 等它跑完 → 在「预览」页签看结果。

**想请你重点帮我看这几件事**

1. **需求理解对不对** —— 它有没有抓住你真正想要的东西
2. **页面结构合不合理** —— 章节顺序、信息密度、重点有没有突出
3. **配图相关性** —— 图片是贴题的，还是明显凑数的
4. **它在哪一步停下来问你了** —— 那些问题问得值不值得，选项够不够用
5. **失败的时候说不说得清** —— 报错信息能不能让你明白下一步该改什么

截图 + 一句你的真实感受就好，不用写长报告。**能复现的 bug 请附上需求原文和项目编号**（项目库卡片上能看到），这样我能直接翻日志。

**几个常见问题**

**Q：为什么非要自己配 API Key？**
A：内测阶段不替大家垫模型费用。用 deepseek 这类便宜模型跑一个介绍页，单次大约几厘到几分钱人民币，具体看你自己的网关定价和账单。**注意**：界面顶部显示的 `$0.04 / $5.00` 和 token 数是模拟值（界面上有标注），不是真实账单，别拿它对账。

**Q：会不会偷偷套模板？**
A：不会。无模型、门禁不过，都会明确阻断并给出失败原因，不会静默降级成模板页然后说成功。

**Q：生成的网页能商用吗？**
A：网页本身是你生成的，随你处置。但配图来自公开图源，每张都保留了可获得的作者与许可信息，商用前请自己核一下许可（公开图源返回的许可字段不等同于对使用权的独立核验）。

**Q：能给我一个能直接点的链接吗？**
A：内测阶段还是本地跑，没有公网部署。等稳定一些会考虑。

**Q：会收集我的需求内容吗？**
A：不会往外传，除了发给你自己配置的模型网关。所有项目文件都在你本地 `workspaces/` 目录。
