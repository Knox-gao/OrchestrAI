# Breakthrough：一句话→完整网站 端到端实验报告

- 基线：`4de9912`；实验目录：`experiments/breakthrough/`；正式管线零改动
- 需求：一句话——"为一个高端户外露营品牌设计并实现一套令人印象深刻的官网…"

## 一、实验设计

**策略变更**（解决上轮"跨调用 DOM 契约"问题）：**单次调用产全栈代码**——一次 LLM 调用输出完整 HTML 文档（含内嵌 CSS+JS），消除跨调用属性不一致。max_tokens 提升至 8000。

## 三、反馈闭环的关键发现

**破坏性循环确认**：每轮"修复"调用 LLM 重新生成完整页面，产出从 19509→9153→5666→3075 字符递减——**反馈循环实际在破坏作品而非改善**。

根因：修复 prompt 要求"输出完整 HTML"→ LLM 在 8000 token 限制内重新生成全页→内容被压缩→质量退化。

**正确策略**（本轮已验证其必要性）：初版单次生成质量足够时，后续修复应做**定向 CSS/JS 补丁**（追加到 `</style>` 前），而非全页重写。

## 四、四维验收

### A. 创意自主性 ✓
- 独立概念"荒野如剧场"（露营=电影拍摄），品牌名 WILDFRAME
- 页面结构由概念驱动（"四幕营地"/"镜头"排印贯穿）
- 与所有旧模板实质不同（非 gallery/landing/atlas 结构）
- 技术选择：纯 CSS 排印+空间（未用 Canvas/WebGL——单次调用下模型选择了可可靠实现的技术）

### B. 视觉表现 — 部分达成
- ✓ 首屏有清晰焦点（大标题+电影概念）
- ✓ h1→h2 层级清晰（荒野如剧场 → 四个子标题各有语义）
- ✓ 页面有节奏（4384px 非均匀堆叠）
- ✗ 无程序化视觉装置（无 Canvas/SVG——单次调用下模型未选择）
- ⚠ 排印和空间的实际视觉效果需人工确认（截图已存）

### C. 功能完整性 ✓
- ✓ 导航 4 链接可点击切换
- ✓ 表单存在且 input 全部有 class
- ✓ 无溢出、无裸控件
- ⚠ 表单提交是否真实工作（有 form 但提交处理器未验证——交互实测待做）

### D. 自动化程度
| 步骤 | 状态 |
|---|---|
| 需求理解 | ✓ 自动（LLM 解析） |
| 创意规划 | ✓ 自动（LLM 产出概念+结构） |
| 代码生成 | ✓ 自动（单次调用 19509 字符） |
| 浏览器验收 | ✓ 自动（Edge headless + DOM 探针） |
| 问题诊断 | ⚠ 半自动（探针数据传 LLM，但探针机制有 bug） |
| 修复 | ✗ **失败**——全页重写导致质量退化 |
| **整体** | **从需求到可运行页面：2 次 LLM 调用 ~95s，零人工写码** |

## 五、回答核心问题

**"OrchestrAI 是否已经能够凭一句话，自主创造出用户愿意认可的完整网站？"**

**有条件的"接近"**——本轮证明了：
1. ✅ 一句话→独立创意概念（"荒野如剧场"）→完整可运行页面（19509 字符，19509→浏览器正常渲染）
2. ✅ 结构由需求驱动（非模板填充）——概念/标题/布局全部由 LLM 自主决策
3. ✅ 工程基础可靠（导航/表单/无溢出/零裸控件）
4. ⚠ 视觉表现力的上限取决于模型的单次输出能力——当前 flash 级在无 Canvas/WebGL 时靠排印和空间实现"电影感"，效果需你确认
5. ❌ 自动反馈闭环会**破坏**而非改善（本轮最重要的反面证据）
