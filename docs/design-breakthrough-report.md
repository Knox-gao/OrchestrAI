## 任务 A：当前原型（stellar-ledger）为何"一般"——证据缺陷清单

观察基础：1440×900 实际渲染（浏览器亲验）+ `ledger-v2-desktop.png` + 代码核对。

| # | 层次 | 缺陷 | 证据 | 影响 |
|---|---|---|---|---|
| A1 | 主视觉表现力 | 恒星只是小圆点+径向光晕，最大星点 ~9px；与背景星野的视觉重量差不足 3×，"数据成为主角"的概念没有被视觉重量支撑 | 截图：画面任意裁角与中心亮度相近；`magToR` 上限 6.2-(-1.46×2.1)≈9.3px | 高 |
| A2 | 首屏构图 | 无构图中心：22 星均匀散布（data.mjs 手工 0-1 均布），无聚散/大小/方向节奏；标题块贴左上、图例贴底，中间大面积均质点阵 | 截图：无任何视觉锚点；`x/y` 分布核对 | 高 |
| A3 | 艺术指导一致性 | "暗底+等宽微字+金色 kick"是档案馆风的**公式化拼贴**：排印成了主角，星点反而失焦——概念与手段错位（参考站的档案排印成立是因为其主角有体量材质） | style.css：10px mono 标签 17 处 | 高 |
| A4 | 叙事节奏 | Brief 写"概念→清单→详情"，实际= 单屏星图+侧卡，无滚动叙事/章节/导览 | index.html 仅一层固定 UI | 中 |
| A5 | 交互探索 | 拖拽=平移均质点阵，无"发现时刻"；过滤=点开关 | app.mjs 巡天实现 | 中 |
| A6 | 模板依赖 | 过度依赖暗色主题与微标签（本原型即如此） | 同 A3 | 中 |
| A7 | 原语限制 | **假设**：heroStrategy 枚举（ledger-label 等）易诱导"标签化首屏"；未在本原型直接验证 | 标注为假设 | 低 |

**结论**：问题不在工程，在**创意概念没有转化为可指认的视觉隐喻**，构图无张力。

## 任务 B：三个实质差异的创意方向（同一需求）

差异覆盖：视觉隐喻 / 明暗基调 / 首屏构图 / 信息组织 / 关键交互 / 移动重组——非换色换字体。

### 方向 1「天球仪 · ARMILLARY SPHERE」
- **创意主张**：把全天亮星装进一台**可旋转的黄铜天球仪**——星不是撒在屏幕上的点，而是钉在球面上的灯。
- **用户第一感受**："这是一台仪器"，想伸手转动它。
- **首屏构图**：中央占高 ~72% 的透视天球（球面星钉+稀疏金经纬线+赤道环），巨大单 体中心构图；标题以铅字块压左下角；图例=球仪底座刻度。负空间包围主体。
- **空间关系**：球体是唯一大形；标题≤12% 高度；其余全部留黑。
- **选择理由**：金色细线+墨黑=仪器室气质（非赛博）；星点因**透视前后径差**自然获得大小节奏（近大远小），解决 A1/A2。
- **叙事**：转动天球 = 翻阅全天；点击球面星钉 = 抽出该星的档案签（从球心拉出）。
- **关键交互**：拖拽旋转天球（惯性），双击复位。
- **移动端**：球仪放大满宽，标题上移，档案签改底部抽屉。
- **避免**：粒子星云、辉光滥用、居中对称的呆板（球带 12° 倾角）。
- **验收**：①静止首屏能一眼指认"天球"轮廓 ②旋转时星钉前后径差可感知 ③点击星钉 300ms 出档案签。

### 方向 2「摄谱长廊 · SPECTRAL PLATE」
- **创意主张**：把恒星按光谱排成**七条水平谱带**（O 顶→M 底），整页像一张竖读的**光谱底片**——星等是点的直径，光谱是带的颜色。
- **第一感受**："在读一张天文底片/摄谱仪记录"。
- **首屏构图**：满幅水平节奏（七条色带全屏并列），每带左端一枚大型谱型字母（衬线大字），带内星点沿水平基线排布；无中心主体——构图张力来自**带间色彩渐次与疏密**。
- **空间关系**：字母=章节锚，星点=内容，行间留白=呼吸；点击星点行内上方浮现序号与名。
- **理由**：信息组织从"按亮度"换为"按光谱分章"（实质差异）；纯排印+色带零素材依赖。
- **叙事**：从蓝到红读下去=从短命蓝巨星读到长寿红星（带一句章引言）。
- **关键交互**：点击带内星点→该行上方展开"底片注记"（等宽小字档案），带高微增。
- **移动端**：七带改纵向卡片谱列，字母改左侧竖排。
- **避免**：卡片网格、hover 发光、暗底渐变。
- **验收**：①七带色序一眼可辨 ②任一星点点击有行内注记 ③移动端无横向滚动。

### 方向 3「子夜观测志 · MIDNIGHT LOG」（浅色方向）
- **创意主张**：一本**天文台手绘观测日志**：米纸、墨点星图、红笔批注——档案感来自纸与墨，而非黑底金线。
- **第一感受**："翻到了一册真的手账"。
- **首屏构图**：纸面满幅（#efe9dc），细灰坐标网格；恒星=**墨点**（直径=星等，边缘带枯笔渗墨感）；少数亮星有红笔圈注+引线小注；左上是手写体日期与"第 N 夜"；构图=纸面散点+批注的聚散（刻意在两处制造密簇）。
- **空间关系**：墨点是主角，红批注是视觉次焦点，网格是纸的肌理（不抢戏）。
- **理由**：彻底跳出暗色套路（A6）；"档案"由**材质**表达而非颜色公式；浅底深字可读性佳。
- **叙事**：按"观测夜"分页（一屏一夜），页脚有手写页码。
- **关键交互**：点击墨点→**纸卡翻出**（像贴在日志上的索引卡，带轻微纸影）。
- **移动端**：日志改竖翻页，网格密度降低，红批注字号增大。
- **避免**：暗底、发光、等宽字满屏（仅数据行用）。
- **验收**：①纸材质感一眼成立 ②墨点大小与星等对应可感 ③翻卡交互 ≤300ms。

## 任务 D：两轮迭代（方向 A）

**迭代 1（构图层）** `shots/A-iter1-before-after.png`
- 问题（截图定位）：球体偏小（R=0.34）且中心偏上（0.46H）；底盘暗晕脏（无光源方向）；铭牌信息单薄
- 归因：创意→构图参数；组件→canvas 渐变
- 修复：R=0.385 / 垂直居中 0.5H / 左上受光自然球面阴影 / 铭牌加仪器参数行
- 结果：中央装置体量感显著增强（亲验+截图对比确认改善）

**迭代 2（叙事/交互层）** `shots/A-iter2-before-after.png` + `A-iter2-mobile-390.png`
- 问题：转动天球无"翻阅"反馈；星标签仅 4 颗亮星有；hover 无光标反馈
- 归因：交互层（叙事缺失）/ 信息密度策略
- 修复：底座**经度读数**（实测 LON 034°→025° 随转动更新）；近侧星标签全显；hover=pointer+可点
- 实测：环扫 36 采样点命中星钉（牛郎星档案签正确弹出）；移动 390×844 无溢出、球满宽
- 评审工具教训：外部复算投影坐标与运行时姿态有偏差导致两次"假 miss"——**交互实测必须用页面内探测**，已记入方法库

## 任务 E：可复用能力提炼（回灌建议，未实施）

1. **概念→构图转换器**：Brief.concept 需附"视觉隐喻物"字段（如"黄铜天球仪"），heroStrategy 由隐喻物推导（装置→中心构图；底片→满幅节奏；手账→纸面散点）——这是本实验最大增益：**隐喻物给构图一个可执行锚**
2. **Brief 视觉焦点/空间关系**：新增 focalObject（主视觉占屏比例+位置）与 negativeSpace（负空间承诺）两字段即可驱动构图，无需更多枚举
3. **截图问题→修改任务**：本实验证明"问题-位置-归因层（创意/构图/组件/响应式）-定点修"四段式可执行；建议进 supervisor 视觉审查的事件结构
4. **局部修 vs 重设计判据**：构图锚点缺失（A2 级）=重设计信号；参数级问题（间距/颜色）=局部修——缺陷清单分层（任务 A 的 7 层）即判据
5. **策展增强**：图片媒介分类（curator 已有）应增"构图角色"标注（主体图/氛围图/数据图），与 focalObject 联动
6. 不自动化：创意辨识度等主观维度保留人工评审+评分者记录
